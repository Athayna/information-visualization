# Information Visualization

This repository contains assignments for the course "Applied Visual Computing: Information Visualization" at Hochschule RheinMain which is part of the Master of Science in Media Computer Science.

## Software

The course mainly focuses on information visualization using the open-source JavaScript library [d3](https://github.com/d3/d3).

## Structure

Each assignment is worked on in it's own directory.
The original assignment given by the professor is copied into a `README.md` in each directory.
